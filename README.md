# Portafolio de Brayan Santamaría

Portafolio de un estudiante de Ingeniería de Telecomunicaciones enfocado en redes Cisco, operaciones NOC e infraestructura Linux. Presenta mi trayectoria, incluida mi experiencia en operación y mantenimiento de red fija en Claro.

- [Abrir portafolio](https://brayansantamaria.dev/)
- [Ver el código de la página](index.html)

## Ejecutar en local

```bash
git clone https://github.com/brayansanpr1694/portfolio.git
cd portfolio
python -m http.server 8000
```

Abre `http://localhost:8000` para ver el portafolio. La página usa HTML y CSS y no requiere un paso de compilación.
