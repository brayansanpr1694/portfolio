Sistema de monitoreo de red — Proyecto de investigación
↗

Proyecto en fase de investigación: backend en Spring Boot para detectar anomalías y monitorear en tiempo real la red de un campus institucional. Objetivo: reducir el tiempo de detección de anomalías de horas a menos de 30 minutos, con una API REST y un panel de alertas.

Java Spring Boot Redes REST API
Fase de investigación · diseño en GitHub
🏎️
SIIMA Vektor — Sistema de telemetría para vehículo eléctrico
↗

Integrante del equipo de telemetría del vehículo eléctrico monoplaza SIIMA Vektor (UTS). Diseño basado en ESP32 (se evaluó el ESP32-C5 por su CAN FD; en el montaje final, ESP32-WROOM): lectura del BMS de la batería de 48 V, sensor Hall para RPM, RTC DS3231, registro en doble microSD y transmisión en vivo por LTE con el módulo SIMCOM A7670SA. Presentado como ponencia en el X CISIET 2026 (Universidad de Antofagasta, Chile).

Embebidos CAN FD IoT / LTE
Caso de estudio en GitHub
